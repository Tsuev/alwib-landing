# Alwib

Лендинг основного проекта [store.alwib.ru](https://store.alwib.ru) — SaaS-платформы для быстрого создания современных онлайн-витрин и интернет-магазинов.

Alwib помогает предпринимателям без разработки с нуля запускать собственные витрины с каталогом товаров, страницами услуг, контактной информацией и возможностью принимать заявки от клиентов.

Платформа построена на мультитенантной архитектуре: множество магазинов работает на одном экземпляре приложения, при этом данные каждого магазина полностью изолированы.
